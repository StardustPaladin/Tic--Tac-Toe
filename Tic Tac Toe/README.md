# Overview

I created a Tic-Tac-Toe game using C# to improve my programming skills and learn how to build applications with a graphical user interface. The game allows two players to take turns placing Xs and Os on a 3-by-3 board. It checks for winners, detects ties, and keeps track of each player's wins.

My purpose for creating this software was to practice C# concepts such as variables, arrays, conditionals, loops, methods, classes, and file handling. I also wanted to learn how to create a graphical interface and make buttons respond to user input.

For an additional challenge, I added file input and output so the game can save the scoreboard and load previous scores when it starts again. This project helped me understand how different parts of a C# program work together to create a functional application.

[Software Demo Video](https://youtu.be/cLivBf4aUJI)

# Development Environment

I used Visual Studio Code to write and edit my code. I used the .NET 9 SDK to build and run the application on Windows.

The programming language I used was C#. I used Windows Forms to create the graphical interface, including the game window, buttons, and labels. I also used the System.Drawing library to control the appearance and layout of the game and System.IO to save and load the scoreboard using a text file.
